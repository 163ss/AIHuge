# 4、故事剧情概要
朝野视 @太子萧景宣 为废储， @誉王萧景桓 与谋士 @梅长苏 设家宴寒毒局欲一举废储。太子在东宫偶得域外进贡的 @牛牛智能玩偶 ，其唯一功能是以剧烈震动预警危险。家宴敬酒前玩偶双重报警，太子借身体违和请验膳食，检出寒性毒残； @梁帝 震怒，限誉王二日彻查。次日朝堂，梅长苏借户部旧案请削东宫属地，玩偶再预警，太子当庭拆穿只查现任、避谈积弊的党争意图，梁帝准新旧并查、暂缓削权。誉王与梅长苏断定东宫藏异，夜遣死士潜入；玩偶示警杀机，太子提前戒备，护卫生擒活口。消息传至苏宅与皇宫，誉王、梅长苏、梁帝同疑太子依仗，齐声追问“难道是她？”并出发东宫。
